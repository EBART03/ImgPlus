To Save Images

  1. Right Click on the Image
  2. Select the "Save Image in ImagePlus"

To Add Tags

  1. Click on the "+" button
  2. Enter the tag name
  3. Click "Add Tag"
  4. Click "Cancel" to close the popup

To Add Tags to Images

  1. Click on the image
  2. Select the tag from the dropdown
  3. Click "Add Tag"
  4. Click "Cancel" to close the popup
  5. Multiple tags can be added to the same image
